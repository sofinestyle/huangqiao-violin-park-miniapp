## 技术建议与当前限制

优先验证**微信原生小程序＋独立网页后台＋腾讯云 CloudBase**。原生技术路线针对当前仅微信的范围；后台具体框架、数据库类型、媒体策略与套餐尚未锁定。先验证预约、咨询、视频三个真实闭环，以及并发、权限、恢复、公司资产归属，再决定实施路线。独立部署服务作为候选备选；不得将工具文档中的“支持”写成项目已经验证。

本轮未创建小程序 AppID、云环境或工作人员账号，未购买资源、绑定远程仓库或部署公网。本地已建立 Git 基线，具体提交以 `git log -1` 为准。
