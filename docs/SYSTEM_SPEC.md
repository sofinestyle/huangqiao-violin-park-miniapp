## 3. 系统架构与模块清单

现行架构：微信原生小程序、Node、PostgreSQL、CloudBase 私有存储、独立静态 Admin（DEC068 之后）。DEC004 当时只是待验证建议。SQLite 只作离线只读恢复（DEC074），不再是 DEC010 那种 API 运行库。

`app.json` 主包 17 条，品牌介绍在分包 `pages/brand`，合计 18 个路由，与 README 及 DEC046 清理后口径一致。2026-10-03 文档审查的“19 页”是清理前数字。五导航：首页、乐器、文创、研学、我的。其余：产品详情、套餐详情、预约、记录列表与详情、咨询、教学列表与课程、导览、关于、报名列表与详情。旧点位详情和模板日志页已删除。

后台菜单（`admin/src/App.jsx`）：工作台、内容维护、场次管理、研学预约、咨询管理、素材库、账号权限、操作记录。角色为管理、内容、接待。服务端覆盖 HTTP、内容、SKU 与咨询快照、报名容量、媒体与视频直传、审计、入口隔离和备份。启动与恢复见 README、[LOCAL_DEVELOPMENT_RECOVERY.md](../LOCAL_DEVELOPMENT_RECOVERY.md)。Git 不含数据库、素材、凭据和备份。
