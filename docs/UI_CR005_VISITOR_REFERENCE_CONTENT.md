## 问题与证据

原HTML的四点位包含多图、说明、标签和分项时长；研学包含产业引言、地区数据、四项服务信息、五套餐、预约及联系人。原文分别在原HTML479—553、556—602、774—790行等位置，完整摘录已保存。

现有tour仅显示cover/name/opening，listPage已读取并decorate完整Content。点位有images/description/opening/visitNote，**没有独立tags及参观项目/时长结构**。site有intro/notice/serviceNote等通用文案，但intro为受保护的完整公司介绍，不能拿来覆盖为地区产业引言；没有专用产业统计、服务保障或多联系人模型。package有参考亲子/单人价及行程，但当前页未完整展示原稿结构；新增展示不能变成价格规则。

`server/service.mjs`42—46行对持久内容字段做白名单过滤，没有tags、visitItems、industryStats、guarantees等字段；只在小程序画静态内容，会失去后台动态维护。用现有正文强行拆解成结构化数据或按id硬编码四站标签，也不符合现有冻结和资料维护要求。
