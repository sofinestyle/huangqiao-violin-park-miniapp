# UI-CR007：研学页同页套餐与后台输入精简

2026年10月2日；状态：已由用户本轮直接指令批准实施C。确认人：项目用户（姓名未提供）。依据：用户七项具体要求及“请执行”，包含研学首屏按效果图1复刻、4∶3多图轮播、套餐主要信息同卡呈现、分项介绍由管理员输入、两类票价及立即预约、删除后台指定输入项。无需重复等待旧UI准备阶段审批。

## 必要范围

- study/index.wxml、index.wxss：参考图的摄影标题、产业引言、数据栏、四项服务图标及套餐卡；品牌栏中间为“工业研学”，沿用五导航。套餐图片按最新指令4∶3，覆盖参考图2原横幅比例；卡片底部通栏预约。
- study/index.ts：本页读取既有套餐接口与images/description字段，将分行介绍映射为圆点列表，兼容旧分号分隔；新增卡内预约入口连接既有booking路径。页内图片失败、空列表及价格缺失呈现，不修改预约提交和确认机制。
- admin/src/Content.jsx：仅套餐编辑移除行程、费用包含/不含、作品与材料数量、集合地点、转场、预约说明、取消改期输入框；套餐介绍改6行输入框并提示每行一项；原多图上传与12张上限继续使用，说明其用于4∶3轮播。
- assets/study下四张小图标：依据参考图几何图标绘制的本页新增衍生资源，无下载依赖、无原图覆盖。

## 保护与确认层次

不删除数据库字段、历史内容或预约快照。后台编辑加载完整原对象并原样带回未展示字段；既有接口、服务端权限、版本校验和审计不变。套餐价格、年龄、时长、名称及介绍继续使用后台动态数据，不把参考图2的材料、票型人数或更完整文字自动覆盖到已发布资料。

“完全复刻效果图1”批准本轮原稿引言、110万把/70%+/30%+及四项文案在参考版页面呈现；这些来自用户提供的原稿，仍属原稿R资料，不是本轮外部事实核验，不代表公司经营数据或优惠计算规则已核定。10人团体优惠仅沿用参考展示，不增加自动折扣、收费或支付逻辑；原D事项仍需正式发布前审核。亲子票未增加原稿未核定的“一大一小”人数规则。

研学报名与团体需求入口保留在套餐后方；保留独立套餐详情路由供既有首页等入口使用，本次研学列表无需打开详情。首页、公共导航、全局样式、预约/登录、API、数据库结构和其他后台模块不变。
