# UI-CR009：教学页面品牌导航与自动视频封面

2026年10月2日，基线65ac3e5。用户明确六项修改指令已授权本次实施，状态C；无需重复等待旧UI准备阶段审批。

## 范围

teaching与lesson两页WXML/WXSS/TS：品牌栏、右对齐视频时长、五导航、动态视频标题、移除详情咨询按钮和观看声明。复用已有导航样式及资源，不改公共导航文件和全局样式。时长沿用现有秒单位，以两位小数呈现。动态标题允许换行，不遮挡Logo。

后台Content.jsx视频分支与新video-cover.mjs：保存缺少images的视频内容时，用浏览器在时间零解码首帧，按原比例生成长边不超过1280px的JPEG衍生图，通过原媒体上传接口保存，沿用源视频授权，写入既有images字段。已设置封面则直接保留；失败提示并中止内容保存，不伪造封面或改视频原件。成功上传但内容保存失败时，表单保留封面供重试复用。时长自动读取、失焦格式化为两位小数，保存仍为数值秒。

该后台操作由用户本轮第4项直接授权。没有新增API、数据库结构或媒体公开权限；原上传审计、内容版本校验、草稿/发布状态机制保持。没有自动播放、自动发布、购物或报名规则变更。其他类型内容、首页、预约、公共导航实现不改。
