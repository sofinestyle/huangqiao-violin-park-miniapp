# SKU-1 Admin规格管理

新增产品默认单规格。旧测试产品仅展示过渡提示，不出现旧规格表单与新矩阵同时维护。新产品替换旧“展示规格”纵向大表单，整产品只有“保存内容”。

单规格：SKU Code、可空参考价、图片入口、启用状态（必须启用，禁用提示）。多规格：最多3个启用维度；名称、值标签、排序上移下移、启停，均以稳定UUID定位。每次结构调整先显示预计组合数，点击“更新组合”进行差分预览；21—50提醒，>50阻止生成/保存。未生成的新结构不能静默丢失已编辑SKU。

高影响确认：值停用提示“停用该规格值将同时停用X个SKU，不会删除历史数据。”；维度停用显示影响数；simple→options说明原SKU用于首个组合；options→simple恰好1启用SKU并确认，>1阻止；新增维度说明原身份绑定首个新值。普通改价/改码无弹窗。

轻量矩阵约56—64px行高：选择、规格组合、SKU编码、参考价、图库来源、启用。Checkbox选择后才显示批量栏：设置参考价/清除参考价（独立动作）、启用/停用、使用产品图库。0和继承明确区分。显示产品图库（继承）或独立图库N张；只打开一行图片编辑区，复用MediaUpload与素材选择，不永久展开每行上传表单。

原Content Drawer对10—20行过窄，仅产品新版编辑器受控加宽至min(1080px,视口-侧栏-间距)，两栏基本资料+矩阵或单列紧凑布局；保留原Drawer键盘、关闭、忙碌保护，不影响非产品内容及其它页面。沿Admin Design System颜色/无衬线/浅横线/焦点；不改全局设计规范。

保存防重入使用ref+busy；上传期间禁止结构变更/关闭/保存；上传回调按稳定SKU id或草稿key关联。Server错误包含field与SKU定位，顶部和对应行显示真实错误。首次保存使用Server返回模型刷新状态，再按现有完成关闭流程返回列表；再次打开使用正式ID。
