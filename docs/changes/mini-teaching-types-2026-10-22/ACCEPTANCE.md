## 根因与实现

原页面复用列表按series/category生成筛选，卡片根据type=video/course/article显示公开视频/课程信息/图文教学；后台业务类型是另一个字段teachingType。两者不是同一概念，不能把所有video都归为某个业务类型。

现在固定显示“全部、开箱教学、产品视频、提琴课程、图文教学、其他”，横向滑动可选择末项。卡片按teachingType显示业务标签，按原type保留视频封面16:9、时长、详情播放器及播放逻辑。搜索与类型条件组合生效，无内容类型保留选项并显示空状态。

| value | 标签 |
|---|---|
| unboxing | 开箱教学 |
| product_video | 产品视频 |
| violin_course | 提琴课程 |
| article | 图文教学 |
| other | 其他 |

原生TS映射与shared/teaching-types.mjs后台既有定义通过契约测试逐项比对。沿用后台对旧article/course的兼容判断；没有业务类型的旧视频不按标题、媒体格式猜测类别，显示“未分类”，只在“全部”可见，不擅自归为“其他”，不回写数据。
