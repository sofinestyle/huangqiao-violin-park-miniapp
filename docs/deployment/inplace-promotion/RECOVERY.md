# 备份恢复与兼容回退

本文件只覆盖本次原地转正，不授权业务数据迁移、删除、云实例恢复或新增收费资源。不得展示数据库连接串、AppSecret、存储密钥、Cookie、会话令牌或解密内容。

## 备份集与恢复证明

本次应用备份包括13张app表、原始Schema SQL、云运行配置和79个媒体对象。业务内容与凭据仅在内存处理后写入AES-256-GCM加密文件；备份放在Git忽略的backups/promotion-*，密钥位于单独的.local/production-backup-keys，目录0700、密钥0600。manifest保存校验值、nonce/tag、文件映射和源快照时间；没有解密密钥无法恢复。临时失败备份不得作为完整备份使用，完整集必须有complete=true的manifest.json。

使用仓库scripts/verify-application-snapshot.mjs作真实离线演练，参数为--backup-directory、--key-file、--test-url-file、--report；仅传本机文件路径，不在命令参数填写密码或连接串。--test-url-file使用本机已有专用测试连接文件，--report必须是.qa下的新文件。脚本拒绝云端目标及非hq_test_*本机库，每次新建隔离数据库，恢复13表，逐行/列核对，恢复全部媒体并核对SHA-256，再验证图片200和视频Range206；结束删除该隔离库和解密媒体。不能指定既有业务库作为覆盖恢复目标。

实际演练结果应记录表数、行数、媒体数与字节、哈希是否一致及清理结果；不记录密码哈希、用户资料或令牌。JSON列的SQL NULL与JSON null必须区别，遇到快照不能明确区分的可空JSON列应拒绝，不能静默恢复。当前快照bookings/changes为空，不存在该歧义。Schema Migration校验和必须与原始SQL一致；不得为通过演练改写基线。

此备份是应用级快照，不是原生pg_dump、整实例镜像或PITR。DescribeBaseBackups/DescribeAvailableRecoveryTime受当前权限限制，实际保留期、最近成功点及恢复窗口待具备权限人员只读确认。本机备份与本机密钥仍有单机损坏风险；正式运营前由负责人安排加密备份离机副本与密钥分离保管，本轮不自行向外部网盘传送。

## 转正前后控制

1. 先确认完整备份、隔离恢复、现有不可变API及Admin制品可用；核对清单批准和当前行指纹。未通过不改内容标记或APP_ENV。
2. 候选先保持维护只读，HQ_READ_ONLY=true；同时保存旧版本、当前配置的加密快照和本次制品SHA-256。DB连接、Schema、媒体桶、Secret、Cookie属性、CSRF及规格不能随环境切换改变。
3. 实测admin.yorray.com真实HTTP Host透传及所有旧入口的拒绝结果，再决定启用正式环境。不能信任客户端可伪造的X-Forwarded-Host/Forwarded，也不能通过关闭入口保护使测试通过。主域名和默认域名均需测试公开读取、登录、写入入口及媒体；内部健康GET例外明确保留。
4. 在维护窗口执行已批准的51条标记事务与1条审计。执行前后比较全部非标记字段、SKU、媒体哈希和其他业务表；任何源变更或不符即停止，不重新生成清单冒充原批准。
5. 配套部署Admin保存兼容与API，保持同源Cookie和CSRF；验证正式域名及合法域名后，才生成可联网正式候选。普通Development不能连接正式库，旧Staging包不能经旧网关写入转正后的数据。
6. 验收期间仅允许批准的身份/会话/登录审计写入，不提交预约、咨询、媒体或内容编辑。手机结果必须来自新候选，注明iOS/Android、版本、操作者和时间。

## 出现异常时

优先保持新兼容API的APP_ENV=production及HQ_READ_ONLY=true，保留入口限制，停止新写入和视频任务，不动业务资料。修复兼容制品后重复只读验收；没有授权不得放开维护。

应用回退不自动恢复数据库或反转isTest；正式访问后可能已有合法新数据。禁止直接把APP_ENV改回staging或恢复旧API011、旧Admin保存规则来“回退”，这会重新开放测试行为。若确需数据恢复，先另列精确范围和差异，取得批准，在新隔离目标验证后安排恢复；不得直接覆盖源库。现有备份/Schema和不可变旧镜像保留作为取证与受控修复材料。
