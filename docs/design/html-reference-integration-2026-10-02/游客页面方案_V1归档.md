日期：2026年10月2日；项目：黄桥乐器文化产业园微信小程序；检查与方案编制：Codex；状态：**检查和方案交付，首批设计及实施范围待用户确认，未修改页面代码**。

建议第一批优化**乐器列表、文创列表、共用产品详情**，用三页建立与已验收首页一致的产品浏览体验，再处理研学申请与本人记录等较复杂状态。当前工程与指定基准一致；主要问题是其余页面仍沿用早期全局卡片样式、辅助信息对比不足、筛选触达偏小，以及测试素材重复。首页仅作为一致性基准，后台及公共导航不列入本轮优化。

## 二 建议优化顺序

每批独立确认具体方案及文件范围、实施和验收；前一批批准不自动授权下一批。用户如优先处理研学，可调整顺序，业务状态与验证准备成本随之增加。

| 顺序 | 页面 | 建议布局与排序理由 |
| --- | --- | --- |
| 第一批 产品浏览 | instruments、gifts、product，共3页 | 目录与详情成对改进，收益直观；三页可局部隔离，已有素材和正常状态可立即做原生验证。咨询入口只检查携带，不先改咨询表单 |
| 第二批 研学与申请 | study、package、enrollments、enrollment、booking，共5页 | 套餐为摄影加开放行程；活动列表突出日期和状态；表单按参加信息/联系信息分组。一次覆盖套餐预约、团体需求、已成团跟团三条现有路径，避免状态风格各自分裂 |
| 第三批 本人服务 | mine、records、record、consult，共4页 | 我的采用清楚服务分组，记录采用状态/日期/安排层级，咨询沿用既有来源区和表单。需提前准备隔离记录及身份测试，不能用私人记录截图充当QA |
| 第四批 教学 | teaching、lesson，共2页 | 列表采用图文目录，类型标识区分公开视频与课程；详情按既有type展示播放器/图文/课程字段。需要实际可发布测试资料和视频，不以当前空页代替正常验收 |
| 第五批 导览与品牌内容 | tour、spot、brand、about，共4页 | 导览为连续编号摄影内容，点位为到访信息；品牌为摄影和完整故事，关于为文档式章节。品牌已有局部设计，优先做差异核查，避免重复投入 |

五批合计18个非首页注册页面，包含相关详情、申请及服务页面。首页与后台均不在上述批次。公共样式/组件保持冻结，先用各页命名空间验证方案；后续如确需抽取公共能力，再列涉及页面、首页回归、文件及状态影响，得到明确确认后处理。

## 三 第一批页面具体设计方案

### 1 共用视觉语言及范围

第一批采用**暖米白开放目录与清楚的产品资料页**。背景沿用#F7F3E9，主文字/主按钮#3C2B24，辅文#6C5948，少量分隔#E5DCCB，#B99A68仅作非关键装饰，不作小正文。页面标题用现有系统衬线回退，正文与搜索/筛选/按钮用系统无衬线；不加载新字体、不新增英文口号、Logo或摄影素材。

S参数：左右留白32rpx，目录列距24rpx，条目间距40rpx；页标题42rpx、条目名32rpx、辅文26rpx、参考信息28rpx、详情正文30rpx/约1.8行高。普通图片圆角16rpx，功能按钮16rpx；去除列表条目整体白底、整框线与阴影。高度随内容增长，不把标题强行省略或规定齐高裁文。筛选/搜索/主动作按原生实测至少44px逻辑点击高度，不能只按rpx换算承诺达标。数值是实施起点，最终按320/375/390/430px原生检查调整。

### 2 乐器列表

**布局：页面原标题与原说明 → 搜索 → 横向固定分类 → 两列开放产品目录 → 既有空/错误状态 → 现有底部导航。** 内容区不新增Hero或复刻首页固定品牌栏，减少首屏操作成本；原生顶栏与页面标题层级保留，文案不改写。

分类仍由现有filters循环，完整保留“全部、提琴、吉他、尤克里里、口琴、其他”。采用低装饰圆角矩形触达区，选中深木色及暖白字、未选深棕文字与必要底色；横向滚动沿用原scroll-view，不新增二级分类、自动置顶或滚动逻辑。

每个条目先展示原后台cover的**1∶1方形图**，下面开放排列原categoryLabel、name、priceLabel和“查看详情”。分类作为小型文本层级，名称为识别重点，参考价/咨询报价作为必要资料，避免促销语气；原资料完整保留，不加库存、销量、折扣、推荐徽标。条目整块bindtap=open与按钮catchtap=open均保留；首页提琴入口的预选、清空旧搜索及一次性键消费均不改。

### 3 文创列表

**布局：原标题与说明 → 搜索 → 动态系列筛选 → 两列开放作品目录 → 既有状态 → 现有底部导航。** 与乐器统一色彩、字号和触达，但以现有series文字强调系列，再显示产品名、参考信息及详情动作，形成作品目录感。

系列仍从后台已有资料动态派生，不能写死当前几个系列、重新分组、改变排序或加入“热销/限定/必买”。每张封面保持1∶1，不叠加价格或名称遮挡产品照片；保留现有aspectFill显示方式，不处理源图片。当前图片重复通过后台资料维护解决，本批不另建艺术化商品图或拼接展示未经确认的成品。

### 4 共用产品详情

**布局：原图库 → 名称及编码/类别/品牌 → 参考信息与原priceNote → 原规格横栏 → 当前规格说明及规格参考价 → 完整产品介绍 → 原咨询操作区与线下成交说明。** 乐器和文创共用一套资料层级，不增加按品类分支或新详情字段。

图库保持现有swiper、指示点、宽度和430rpx框架高度，沿用galleryImages与原preview/imageError绑定；**建议仅本页image mode由aspectFill改为aspectFit**，用暖白底承接可能出现的留边，使整琴与含字产品图完整显示。这个建议不修改源文件，不改变详情框架比例，也不影响列表封面；原图预览仍调用当前处理。产品照片比满框更重要，但留边是否接受须在本方案确认中明确。

名称与介绍不覆盖在照片上，编码/类别/品牌辅文仍完整呈现。产品参考价、报价模式、priceNote和已选规格价格保留原条件与取值，不新增“起价”“应付”或价格计算。规格区扩大触达并强化选中态；切换后由当前TS更新图库，不能改为新的筛选或购买规格机制。规格说明容器降低整框卡片感，以分隔和暖色局部底组织，空描述仍按现有条件呈现，不擅自隐藏默认规格。

原sticky-action保留既有粘性行为和安全区，深木色“咨询此产品”为主，phone存在时显示次级“电话咨询”。可在现有容器内排成清楚的主次按钮，保持所有原事件与条件；不新增购物车、客服SDK或固定交易栏。“首期提供展示与咨询，不支持线上购买。”原文继续完整显示。详情返回使用现有原生机制，不增加页面导航。
