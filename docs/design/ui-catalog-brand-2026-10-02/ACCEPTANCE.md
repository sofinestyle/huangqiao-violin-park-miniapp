## 实施范围

源文件仅为pages/instruments、gifts、study、product、package各自的index.wxml与index.wxss，共十个文件。五页顶部使用YorRay原Logo与“黄桥琴旅”品牌栏，参照tour的55px吸顶深棕栏；各页原生标题、栏目标题、全部业务内容和原有入口保留。背景与tour统一为暖米白。

乐器和文创仍是1∶1图片列表，研学页面保留报名及套餐入口。两类详情增加首页、乐器、文创、研学、我的五导航，产品按item.category高亮乐器或文创，套餐高亮研学；咨询和预约动作区避让52px导航及底部安全区。导航采用页面内原生navigator/switchTab，只读引用既有公共导航WXSS；公共组件本身及首页未改。后续若公共导航结构调整，需同步这两页的标记。

没有改TS、JSON、app.wxss、app.json、公共组件、API、数据模型、后台、登录或预约。没有改内容记录、价格、容量或原始图片。原页面主体通过源码字符串完整性比较保持一致（仅移除列表页已由外层统一承担的底部内联留白），详见source-check.json。
