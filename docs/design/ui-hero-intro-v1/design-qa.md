# 首页主视觉背景及文案排版 Design QA

## 对照依据与证据

以用户本轮附件1作为背景，以附件2作为文字层级和位置参考，以用户给出的标题及完整介绍作为文案依据；继续遵守 Design System v0.1。附件1已原样保存为 `docs/design/references/homepage-workshop-background-20261001.png`，附件2保存为本目录 `reference-layout.png`。参考图是排版方向，不要求复制其背景、字体文件或像素位置。

已实际打开并查看本轮参考及微信原生实现，把两者放入同一图像进行比较：`design-qa-comparison-390.png`；文字局部同图比较为 `design-qa-typography-detail.png`。最终独立主视觉为 `hero-after-390.png`，完整页面为 `homepage-after-390-full.png`。不是根据源码或旧截图作结论。

原生逻辑宽度390px，iPhone 12/13 (Pro)，windowHeight 671px；截图原始尺寸618×1334，内容截图比例618/390，不能直接用设备pixelRatio=3推算截图。比较图统一到390像素宽；附件2原始430×464，等宽后约390×421；本轮主视觉390×488。两者高度不同：本轮需要展示完整介绍，并保留新背景的工坊叙事空间，属于本轮明确设计选择。

## QA迭代与修正

1. 第一轮：标题字重较参考图轻，记录为P2，结果blocked，证据保存在 `qa-iteration-01/`。将标题字重声明从600提高至700。原生计算样式已确认700；实际字形继续采用项目已批准的中文衬线字体栈，与图片中的字体不完全相同。
2. 第二轮：局部亮色琴体影响暖黄色标题。实际字形位置最低对比度约2.90∶1，低于大字号标题3∶1要求，记录为P2并保持blocked；证据保存在 `qa-iteration-02/`。只加深文字区域垂直蒙版：48%位置alpha从0.36调整到0.54，顶部28%仍完全透明。
3. 最终轮：重新编译、采集原生截图、打开同图对照和文字局部，重新测量原生背景。白色标题整框最小4.84∶1，暖黄色标题3.74∶1，正文7.71∶1，均通过对应3∶1／4.5∶1阈值；详见 `contrast-results.json`。此检查涵盖文字整框内所有背景像素，包括未印字位置，比仅检查字形位置更保守。最终未发现本轮主视觉中仍需修正的P0/P1/P2问题。
