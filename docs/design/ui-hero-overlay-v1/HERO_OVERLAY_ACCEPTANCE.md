## 基准及修改

实施前main工作区clean，基准Commit为 `f47a418307e83b810f3d98026cef689e66781033`。仅修改首页两个源文件：

- `miniprogram/miniprogram/pages/index/index.wxml`：给现有背景图片和蒙版增加独立展示层，保留图片绑定、标题和正文绑定、事件、条件及循环。
- `miniprogram/miniprogram/pages/index/index.wxss`：正常态背景层向上延伸55px，图片展示框相应扩大；标题字重700改为900。增加状态区域的CSS保护，防止图片覆盖读取提示或错误重试按钮。字号、配色、文字位置、55px／90%不透明固定品牌栏，以及服务区以下全部样式保持。

背景层原生top=0，高543px，其中55px位于品牌栏背后，品牌栏下方仍显示488px。图片元素580×543px，右对齐，由390px宽背景层限定显示范围；原图无损保留。标题在当前微信原生截图中明显更粗，两行结构和完整117字正文保持。正文、导览按钮、服务区、页尾及整页高度均与本轮修改前相等。

本轮没有重新上传媒体，没有执行后台内容更新，继续读取前一轮既有的 `site.images[1]`、`site.heroTitle`、`site.heroSubtitle` 和 `site.intro`。不改数据模型、API、数据库结构、后台或业务逻辑，不新增字体、资源采购或云配置。
