## 视觉变化

摄影Hero成为第一视觉，两行原有中文标题置于左上暗部，避开关键琴体；保留原图、原Logo及数据来源。Hero高度从首轮840rpx校正为760rpx，约750∶760，以当前竖构图保护琴头及下琴体；深木色导览动作承接主视觉。六入口按产品、体验、服务编为开放行，取消原三列两行的白色描边卡片，并用文字与箭头表达点击。

完整公司介绍原文移至开放式品牌故事区；探索采用01编号、中文衬线及首点位大图/其余紧凑图文；推荐采用02编号、开放式单列摄影与“查看详情”。暖米白承载正文，胡桃木承担主色与页尾，香槟金限于小线条和少量编号语气，无常规卡片阴影。中文层级高于两处章节英文，没有新增口号、手写签名、价格、数量或优惠。
