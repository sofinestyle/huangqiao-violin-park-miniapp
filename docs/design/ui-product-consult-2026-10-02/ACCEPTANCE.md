# 乐器列表、产品图库及下单咨询页调整

2026年10月2日；执行人Codex；用户最新三项指令见DEC034。基线main / b7e7d17，开始工作区干净。

## 修改与边界

源码仅五文件：instruments/index.wxml、product/index.wxml与index.wxss、consult/index.wxml与index.wxss。乐器页移除内容区“乐器展示”、其下说明和卡片“查看详情”按钮，保留整卡详情点击、搜索与五分类；文创列表保持。原生导航栏标题保持，本次去除的是页面内容区重复标题。

产品详情新增按容器宽度等比撑高的方形图库容器，swiper与图片填满该容器；乐器和文创共用详情页均适用。保留galleryImages条件、轮播数据、aspectFill、预览和图片错误处理，未覆盖原图、上传图或更换URL。

咨询页增加YorRay/“下单咨询”深棕品牌栏及五导航；导航只读复用公共样式，原生navigator连接已有五个tab。乐器/文创/套餐咨询按原kind/category显示选中栏目，通用咨询不强制高亮。内容区“联系咨询”和独立“查看资料使用说明”按钮删除，既有说明查看方法移至勾选文案中的下划线“隐私与服务说明”；提交逻辑、字段、同意状态和busy/submitError保持。名称不增加交易、下单或支付能力。

首页、全局样式、公共组件、JSON、TS、API、后台、数据模型未改。原件25份SHA-256校验和git diff --check通过；源码比对显示咨询页原字段、同意与提交绑定保持，只有privacy绑定从独立按钮移至句内文字。测试未提交业务数据。

## 检查中的失败与修正

1. 初版按vw/rpx计算图库高度，390px实际宽358、高357。原生断言发现1px取整差，改为百分比撑高的页面局部容器；复测宽高均358。失败记录attempt-1-gallery-rounding.json与gallery-diagnostic-390.png保留。
2. 官方自动化在表单输入/返回阶段两次响应超时，界面中输入已显示且说明页可打开、返回。保留attempt-2-automation-timeout.json与attempt-3-back-timeout.json；通过原生CUA补核返回后的草稿、未勾选状态和勾选/取消，再继续剩余检查。未以超时当作通过，也未因此修改业务代码。
3. SDK的button.disabled返回字符串“true”，检查脚本按布尔值断言失败；按实际返回类型修正断言后继续。attempt-4-disabled-serialization.json保留。本轮原生脚本以文本归档，未添加永久业务测试。
