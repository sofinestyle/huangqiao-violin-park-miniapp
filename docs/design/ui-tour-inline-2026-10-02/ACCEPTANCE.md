## 失败尝试与恢复

1. 修改前捕获时本地8787服务未运行，tour截图真实显示连接失败，spot读取item为undefined使原双页脚本失败。before-tour/spot截图保留为异常现场，不冒充正常基线；正常旧版参见上一批ui-tour-phase1的截图。本轮先保留源码和数据摘要，再启动已有服务；7张表摘要前后均一致。
2. 官方SDK未能通过park-navigation/custom-tab-bar/.park-tabs定位此次复用组件，定位断言失败；随后以CUA原生控件逐一实际点击和SDK路径/截图观察验证导航，未把定位失败改称成功，也未为测试改公共组件。
3. 城市客厅左滑尝试回弹，未通过；更长距离向右实际滑动成功，读取current从1变0。
4. 430px设备切换时工具退出；重开现有工具、通过官方SDK恢复本地连接后，430px核查与截图通过。后续用户界面状态变化时只读取现况，停止继续切换，保留430px预览。
