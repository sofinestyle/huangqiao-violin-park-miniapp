## 一 设计结论与授权范围

品牌页以“瑜瑞 YorRay”为主角，采用已确认主标题“以诗入琴”，以名字的诗意、瑜与瑞的寓意、品牌表达及企业背景组织完整内容。首屏建立品牌识别，正文分章阅读，页尾承接“查看乐器”和“联系咨询”。延续暖米白、深胡桃木与少量香槟金，以留白和摄影建立层次。

本次只交付详细设计方案及可审阅的页面设计稿。用户已明确选择“仅制作详细方案和页面设计稿，暂不修改小程序”。小程序页面、API、数据库、后台、路由及现有业务逻辑均不在本次实施范围；设计稿中的尺寸、状态与按钮示意不等于原生功能已经实现。

### 现状与改进重点

本轮读取品牌页源码及本地已发布站点资料，现有页面先显示“黄桥琴旅”，随后为提琴图片、运营主体及完整介绍，尚未呈现附件的品牌文化正文。设计判断是品牌身份与内容层次不足，而非单纯配色问题；现有源码能够证明内容结构，历史截图不作为本轮新页面验证。

## 二 页面架构与逐模块设计

推荐顺序为：品牌首屏 → 名字的诗意 → 瑜与瑞 → 以诗入琴 → 品牌与企业 → 服务入口。采用一页自然纵向阅读，保留原生导航标题“品牌介绍”与返回；不新增底部导航，不改变已有五导航。

### 品牌首屏

深胡桃木底色上方居中展示现有YorRay透明标志原件，不增加小块底框、描边、阴影或色彩滤镜。下方依次呈现“瑜瑞 YorRay”“以诗入琴”和“名字是世界上最短的诗。”。主标题是最强的中文信息；名称解释品牌，辅助句引导后续故事。首屏下方露出通栏提琴摄影，不出现价格、立即购买或企业长介绍。

390逻辑像素宽参考：品牌区域左右24px，顶部40px；标志宽176px、高度按原比例约78px；品牌名16px；主标题34px、行高1.4、轻微字距；辅助句15px。首屏文字区约300—320px，自然增长。照片约240px高，采用显示裁切，不改原图。设计稿不绘制假的微信状态栏、胶囊或系统导航条。

### 名字的诗意

暖米白底，章节短英文“BRAND CULTURE”与中文标题左对齐，正文左对齐。“名字是世界上最短的诗”承担首句，日月星辰、山川湖海及想象有形的文字构成完整段落。标题可因窄屏分为两行；正文按屏幕自然换行，不逐行复制印刷稿，也不重复整段英文。

### 瑜与瑞

同一开放式内容区内纵向排列两个释义单元，使用大字“瑜”“瑞”与右侧短句建立视觉记忆。两个单元之间采用细分隔线，不做并列窄卡。汉字约48px，右侧解释17px、辅助词13px；辅助词“光彩”“信意”为内容提示，不新增独立品质承诺。空间不足时解释自然换行。

### 以诗入琴

以现有提琴图的琴体与琴弦局部显示形成视觉停顿；下方为独立米白文字区域，逐行展示附件结尾三句。图片不承载文字，也不以拍摄氛围证明YorRay自有工厂或手工制作能力。不增加第二条主口号。

### 品牌与企业及服务入口

企业章节先展示项目现有城市客厅外景，再展示“品牌与企业”、运营主体全称和当前完整公司介绍。公司全称只设自然换行，正文不删减、截断或折叠。最下方并列保留“查看乐器”“联系咨询”，窄屏及大字模式允许纵向排列。按钮不悬浮，页尾保留安全区。

### 间距与图像

正文左右24px；320px窄屏为20px；章节主要上下留白32px；标题到正文16—20px；同组段落12—16px。通栏图不加装饰圆角，局部工艺图可采用8px圆角。默认无阴影。按钮高至少48px、间距12px、圆角8px，实际点击目标不得小于44px。

首屏摄影高240px；诗意过渡图采用4∶3显示窗口；企业外景为3∶2。这些比例只属于本品牌页的设计建议，不覆盖已确认乐器与文创列表1∶1、研学卡4∶3及教学封面16∶9。

普通正文以4.5∶1为设计目标，深色首屏使用暖白不透明文字。纯色组合将记录计算结果；图上不放必读文字，避免把纯色对比度计算误用于照片区域。

### 素材清单

附件的红色标志与建筑照片提供内容及视觉依据，未另行提取成正式品牌资源。现有透明标志可以在深棕背景正常显示。建筑章节采用项目现有独立外景原图，避免把附件压缩截图误当高质量摄影原件。若必须使用附件同机位照片，后续取得独立原片。

原件不覆盖、不改名、不批量压缩。设计稿引用的副本与来源摘要记录于素材清单；浏览器的object-fit及object-position只是显示裁切，不修改文件像素。主图的真伪、工厂归属和授权不因出现在设计稿而得到核实。

### 响应布局

320、375、390及430px分别检查。320px左右留白20px，主标题30px，故事标题及公司全称允许自然换行；按钮必要时纵向排列。375—430px保留24px留白，图像按容器显示，汉字释义纵向编排不变。不把页面整体缩小到适配窄屏，不以省略号替代完整正文。

设计审阅器提供正文放大到120%的选项。放大时增加段落和模块高度，标题、释义及企业全称不使用固定单行高度；该选项只是网页设计稿的适配检查，不等于已验证微信系统字体放大或真机显示。

底部不设置固定操作条，最后一组按钮之后留出约32px及设备安全区。原生导航标题、胶囊和返回区由微信保留，设计稿不画假的系统界面。品牌页作为现有非tab内容页，不新增五项导航副本。

### 动效与成本

仅设计120—180ms按钮按下反馈，不做首屏入场、自动轮播、背景音乐、视差或自动播放视频。静态审阅不采购字体、不新增平台资源、不部署公网；后续摄影授权、资源处理和媒体流量按实际需求核算，现阶段不承诺固定上线费用或日期。

## 六 交互及页面状态设计

设计稿的交互只用于审阅，不能提交预约或咨询。按钮示意说明其将来沿用的已有去向，不触发后台、不登录、不改变真实业务记录。

| 状态 | 页面表现 | 设计审阅器表现 |
| --- | --- | --- |
| 正常 | 全部品牌内容、完整企业介绍与两个按钮可见 | 默认显示，可自然滚动 |
| 加载 | 稳定米白区域，显示“品牌资料加载中…” | 人工切换到加载示意，不发请求 |
| 错误 | 清晰深色错误说明及“重新加载”按钮 | 重试仅返回正常稿，不声称服务器恢复 |
| 资料未发布 | “品牌资料暂未发布，请稍后再试。” | 不展示虚构公司或占位宣传数据 |
| 图片失败 | 原比例浅米色区域及“图片暂未加载” | 审阅器可模拟，正文和两个按钮仍可见 |
| 大字与窄屏 | 正文换行、模块自然增高、按钮可堆叠 | 120%文字及多宽度审阅 |

现有品牌页已经具备loading、error、重试及site为空的判断。品牌独立图片失败处理目前未在该页实现，因此图片失败态只完成设计；以后若增加失败事件或状态字段，须列入实施范围，不把示意当既有能力。

“查看乐器”沿用/pages/instruments/index，“联系咨询”沿用/pages/consult/index。保持原动作与业务含义；不增加在线购买、自动咨询提交或自动接待确认。按钮默认、按下及键盘焦点在网页稿中可辨；真正的小程序入口点击及平台辅助功能另行验证。

### 阅读完整性

品牌文化中文主体与当前公司介绍完整呈现。主标题重复出现在结尾诗文是附件内容的保留，不再新增“让美有声”。辅助英文不承担唯一信息。用户浏览品牌故事无需新增登录或手机号授权；未来只能沿用已有公开读取能力。

照片失败、加载和资料未发布不能互相替代：未发布说明内容状态，图片失败说明素材加载，网络错误说明读取失败。若原系统区分不足，本次只记录，不在设计阶段修改逻辑。

### 后续实施前需确定

品牌所属法人及公开关系句；主图与外景的正式使用授权；品牌文化是固定审核文案还是后台独立维护；现有图片失败态是否纳入实施。上述事项不影响本次设计交付完成，也不能通过设计文件自动获得业务批准。

## 七 内容维护与后续实施控制

当前品牌页仅读取/api/public/content?kind=site，企业介绍来自site.intro，主图来自site.images[1]，标志为本地原件。没有独立品牌文化字段，不能宣称新的品牌故事已经具备后台动态维护能力。

本次设计稿把公司介绍作为只读快照展示，品牌故事来自附件的审阅文案；它不是正式内容库。后续应在两种维护方式中明确选择：固定审核文案适合更新频率低的品牌文化，但改文案需发版；后台独立品牌资料适合持续维护，但需要额外字段、校验、编辑及发布保护。这是技术方案待选，不由本轮设计替业务方决定。

不得将品牌故事追加到site.intro以复用字段，因为该字段同时供其他页面展示企业资料，可能造成首页或关于页面内容串用。也不把企业介绍改写为品牌宣传段落。若增加独立资料，另立最小Change Request，说明数据字段、后台维护、发布状态和历史资料兼容。

后续实施先记录原生基线，再完成页面局部调整，检查320/375/390/430px、长文本、大字及图片主体；实际点击两个入口并返回；检查加载、错误、未发布和经批准的图片失败；比对公司正文、品牌文化及原件摘要。原生编译、iOS/Android真机及辅助功能必须单独记录，不用本轮网页截图替代。
