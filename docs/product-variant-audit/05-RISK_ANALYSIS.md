# 风险、工作量与验证边界

本表等级是本次架构审计判断，不是已发生事故的断言。成本按相对复杂度，不给虚假精确工时；不含ERP/独立站实际接入。

## 1. 风险矩阵

| 风险 | 等级 | 影响 | 缓解建议 |
|---|---|---|---|
| 数据迁移丢字段/空值或覆盖并发修改 | High | 原规格参数、图、价格及人工修改丢失 | 全量原JSON归档、逐字段diff、幂等映射、版本门槛、事务及隔离恢复演练 |
| 旧Admin整JSON写入覆盖新SKU | High | 已生成矩阵被旧页面保存破坏 | modelVersion、单权威写入、旧写显式阻断/验证适配；切换窗口列入DCR |
| 咨询历史依赖名称 | High | 重名/改名导致错误关联，伪造历史SKU归属 | 保留原快照，不追填；新skuId归属校验，旧名称仅无歧义适配 |
| 媒体引用扫描遗漏 | High | 正常图片410，或停用/未发布媒体被错误公开 | SKU引用、usedBy及公开授权一起升级，权限/Range/下架回归 |
| 游客端选择与价格回归 | High | 标签/图片/参考价错配；旧页面提交失败 | 兼容投影、选中ID、旧包契约测试；价格模式语义单独确认 |
| 自由文本映射 | Medium | 解析“4/4棕色”错误，材料被当成选项 | Legacy无损保留，人工映射，不按名称相似度静默合并 |
| SKU组合爆炸 | Medium | 大矩阵难维护、请求超限 | 维度/值/乘积限制，生成前预览，服务端同等校验，历史另存不删 |
| Option/SKU维护复杂度 | Medium | 单规格也被迫填写多层表单 | 简单模式、仅编辑差异、批量操作及清楚覆盖提示 |
| 过度设计 | Medium | 四表字典/库存/多币种/同步平台扩大范围 | 推荐产品局部Options JSON+一张SKU表，暂不做共享属性和交易 |
| A的长期技术债 | High | 名称继续充当身份，未来多渠道迁移成本随数据增长 | 若选A必须承认短期过渡，不把临时生成器宣传成结构化模型 |
| 编码/价格业务规则缺失 | Medium | 全局冲突、错误币种/舍入，外部销售价混同 | 编码格式/编辑、币种/精度/继承先DCR，独立ID不依赖编码 |
| 只改文档的运行影响 | Low | 链接或结论写错导致误决策 | 只读证据、逐条核查、仅允许目录内新增；不运行写测试 |
| 当前只读统计代表性 | Low（统计本身）；外推正式目录为High | 将28条测试资料当作公司正式商品结论 | 明确采样范围和isTest，正式上线前重新盘点人工确认 |

现有空名/重名校验缺口为源码事实，当前采样未发现空名/重名；“必然导致当前客户投诉”等说法没有证据。图库文件存在/质量、正式产品覆盖、实际操作耗时未验证。

## 2. 方案成本对比

| 层面 | A | B（推荐折中模型） | 原因 |
|---|---|---|---|
| Database | Low | Medium | A无需改表；B新增SKU及唯一约束/索引、混合模型 |
| Server | Low | High | A复用校验；B组合差分、身份/启停、媒体与咨询、兼容写入 |
| API | Low | Medium | A协议不变；B版本与兼容投影/skuId |
| Admin | Medium | High | A压缩与批量编辑；B维度矩阵、差分确认、简单/legacy模式 |
| Mini Program | Low | Medium | A现标签保留；B先读兼容层，再逐维选择与咨询ID |
| Migration | Low | High | A不迁移；B无损归档、映射、幂等、回退、旧快照保护 |
| Tests | Medium | High | A表单回归；B跨客户端、权限、并发、媒体、迁移组合覆盖 |
| Documentation | Low | Medium | A交互说明；B DCR/协议/迁移手册/管理员操作与验收 |

Low不表示零工作。B的迁移High来自零丢失和兼容要求，不是28条数据的数量。若选择四表规范化，再增加属性关系迁移和服务校验复杂度；若同时接ERP、独立站，需另行评估，不包含在本表。

## 3. 审计实际检查与未执行项

已执行：基准分支/HEAD/clean检查；全链路源码、Schema、迁移与测试断言审查；本地产品只读统计；DB/WAL内容hash核对；25份原件校验；新增文档范围、结构、链接和Git diff核查。证据保存 [AUDIT_EVIDENCE.json](AUDIT_EVIDENCE.json)。

未执行：业务测试、Build、Type Check、浏览器录入、微信真机、无障碍验证、迁移dry-run、写入/删除产品、压力/性能测试、生产统计、备份恢复、ERP和独立站接口验证。本轮没有实现改动，运行写测试或迁移不属于审计授权；这些未执行项不能据历史结果填“通过”。

数据库文件和WAL前后hash一致只证明采样区间持久内容未变，不是运行中系统永远无人写入的保证；没有读取客户资料，也没有用正式数据验证业务闭环。本报告不是上线验收或正式资料认证。
