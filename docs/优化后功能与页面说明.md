## 2. 视觉与展示规则

已实施页面延续暖米白、深棕品牌栏、YorRay原标志及少量金色，样式限制在各页。品牌栏通常高55逻辑px；教学详情长标题可换行，不能要求所有页固定单行。我的页使用浅米色圆角分组、细分隔线、深棕线性图标和金色箭头，五个菜单为我的研学预约、我的咨询、联系工作人员、关于我们、隐私与服务说明；没有新增订单、收藏或设置。

| 图片场景 | 当前显示规则 | 保护与注意事项 |
| --- | --- | --- |
| 乐器、文创列表 | 1∶1 | 整卡可点击，五类乐器保留 |
| 产品详情轮播 | 1∶1，下方额外5px间距 | 规格独立图库优先，缺少时沿用产品图 |
| 研学页套餐轮播 | 4∶3 | 单图不显示多图指示点，多图可左右滑动；图片错误及空图库有占位 |

| 琴音之旅图库 | 固定190px显示高度 | 后台图片数量决定轮播内容；城市客厅当前资料的5图不是所有点位强制5图 |

以上为显示容器，aspectFill可能裁边；不裁切或覆盖原始文件。原DOCX、原HTML及23张图片继续按25份清单校验。

## 3. 琴音之旅

路线引言按用户指定“城市客厅 → 音乐生态湖 → 产业园 → 绿岛”展示。四站正文、名称、图片、标签tags和项目visitItems均读取已发布点位资料。项目名称、说明在左，预计时长在右，每行下方均有虚线；页末为虚线圆角参观提示。

四站当前批准内容分别含4、2、3、3项，共12项。预计时长是说明文字，不参与预约计时、人数或价格计算；“约半天”不等于全部分项相加后的保证行程。详见[四站内容与验证](design/ui-tour-complete-2026-10-02/ACCEPTANCE.md)。

指定的开放待核定/到访咨询两段占位文案仅在本页按原字符串隐藏；后台值未清空，更换为其他正式文字后会显示。固定集合/转场/交通说明已删除；点位详情旧路由清理后不再可进入；后台开放/地址/坐标资料没有删除。参观提示及路线引言为页面固定文案。

## 4. 工业研学与预约

研学首屏采用用户参考中的主图、产业引言、三项统计、四项服务说明，产业正文两端对齐。套餐在同卡内展示4∶3轮播、标题、时长/年龄、圆点介绍、亲子票和单人体验票参考价、立即预约。点击预约直接携带套餐id进入原表单，不需要打开套餐详情；缺价显示“请咨询”，不计算应付额。

套餐名称、编码、图片、年龄、时长、介绍、参考价格和发布状态由后台维护。description按换行或旧分号拆为圆点条目，空行忽略。研学首屏图片路径、引言、统计、服务文案、页末预约提示及两位联系人目前固定在study页代码中，不能在后台套餐介绍框修改。附件文字的展示经DEC037/038批准，但产业统计仍未外部核验；儿童年龄、增购折扣、提前期、线下缴费先后等文字没有转为自动校验、计价、扣款或排序功能。

普通/团体申请中的preferredTime为最多100字的可选自由文本，写入现有request JSON，由后台预约详情和本人记录显示；不是场次id，不占容量，不承诺接待。跟团申请使用已发布活动的固定日期、时段和套餐；服务端拒绝跟团请求携带非空自由时段。后台人工确认仍需选择合法场次并检查容量；提交后仅待确认。

研学跟团列表从研学页通过navigateTo进入，左上角有原生返回箭头；单独作为根页面启动时没有上级，工具可能显示主页图标，不能以该预览状态替代真实入口检查。跟团详情移除两个套餐入口，并未删除全项目的套餐或咨询页面。

## 5. 教学与后台内容维护

教学列表视频封面16∶9，标题右侧靠右显示两位小数的秒数；内容详情品牌栏及原生标题读取内容名称。公开视频浏览不强制登录，离开详情停止视频；实际播放、错误重试与下架保护沿用原逻辑。

后台保存video内容且images为空时，浏览器在视频时间零解码首帧，生成长边不超过1280px的JPEG衍生封面，通过原素材接口上传并关联。已有封面优先保留；生成或上传失败会中止该次内容保存并显示错误，管理员可重试或手动上传封面。时长以秒为单位，两位小数显示并保存为数值；自动封面不代表自动发布，不对旧内容批量回填。

具体套餐、点位和教学维护步骤见[操作说明第7节](本地开发与操作说明.md#7-优化后的内容维护与页面复核)。后台的其他业务模块不属于本批整体视觉重构。
