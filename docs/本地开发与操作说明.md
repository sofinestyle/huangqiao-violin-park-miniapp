# 本地开发与操作说明

日期：2026年10月1日。对象：项目负责人、内容管理员和接待人员。当前所有资料和申请均为本地测试，不用于真实接待。Codex修改磁盘中的项目代码，微信开发者工具编译和显示同一份工程；无需把每次修改手工复制到微信工具。

## 1. 预览和开发

1. 在项目根目录运行 `npm ci`（首次或依赖变化时），然后 `npm run dev`，保持该进程运行。后台代码自动更新，服务端源文件变化后自动重启，SQLite和媒体文件保留。
2. 在浏览器打开 `http://127.0.0.1:5173/admin/`。初始登录信息查看 `.local/admin-access.txt`，由本人输入；文件权限600，不在Git中。管理账户默认不拥有名单导出权限。
3. 微信开发者工具打开 `/Users/aaron/Documents/huangqiao-app/miniprogram`，点击编译。修改代码后的效果在模拟器核对；教学通过首页入口进入，底部只有五项。
4. 开发接口使用电脑回环地址。私有项目配置允许本机HTTP；只能用于本地测试。正式环境配置HTTPS与合法域名，再改 `miniprogram/miniprogram/config.ts` 的接口地址与身份模式。手机扫码不能连接电脑回环地址，真机验证须另建受控测试服务，不以关闭真机校验代替部署。
5. 微信工具服务端口供官方自动化工具连接；本次原生检查不执行上传或发布。`scripts/native-check.cjs` 提供页面检查、虚拟提交及结果复核模式，不能在生产环境运行创建模式。

## 2. 维护资料和视频

进入“内容维护”，选择乐器、文创、首页与企业、研学套餐、教学或点位，新增/修改后保存。现有测试资料在数据层保留isTest标记，界面按CR001移除固定测试提示；这不改变资料性质或上线状态。先用草稿检查，再发布；草稿不对游客公开。编码、系列、规格、参考价、电话、开放说明、图文和排序由后台维护。产品展示规格可独立维护名称、参数、参考价及图片；规格没有独立图库时沿用产品图片。正式逐款实拍资料仍待公司提供。

在内容维护的图片区域直接选择本机图片，填写来源与使用授权，点击上传并添加图片；上传完成后自动加入该内容图库。展示规格中也可直接上传独立规格图片。教学内容选择公开视频类型，在同一表单上传并关联视频，预览读取时长，确认格式可播放后保存发布。素材库仅用于查询、预览、查看关联状态和复用已有文件，无需先去另一个页面上传。原14条视频标题没有视频文件，因此初始化为草稿；不会冒充已能观看的教学片。

本地上传限制为单文件64MiB，支持JPEG、PNG、MP4、WebM并检查基本容器签名。该上限是本地验证保护值，不是公司批准的正式媒体政策；编码兼容、文件大小、转码和视频预算列为D06。上线前应增加服务端媒体探测/转码及云端验证，当前浏览器读到时长不替代服务端转码审核。

下架教学内容后，新请求的视频地址返回410，详情返回404，响应采用no-store。其他仍发布的内容继续引用同一媒体时，该媒体仍可访问；因此停止对外提供文件时须下架所有公开引用。已经被设备缓存或下载的字节无法撤回，正在进行的传输不主动中断。小程序离开视频页时停止播放，重新进入旧详情会核对发布状态。更强的即时撤销及带时效播放地址应在正式云媒体方案中验证。

地图仅在管理员填写并明确勾选“坐标已核实”后开放；缺少坐标显示审核后的地址或待补说明，不猜测位置。服务电话须经公司审核再填，正式隐私文本、发布授权及内容审核责任均未由开发方代替公司确认。

## 3. 处理预约、咨询与变更

在场次管理中明确日期、起止时间、适用套餐、人数上限及接待说明，可以暂停申请。初始数据库不自动生成场次或正式容量。已有确认或历史接待记录的场次不能改日期、时段或适用套餐；需要新安排时建立新场次，保护历史记录。模拟器联调采用2099年虚拟场次和明确标注的测试人数；这些参数不可复制到正式接待配置。一个场次内成人和儿童均按实际人数计数；跨场次共用导师、工坊等资源排班目前由工作人员核对，不提供自动资源排程。

游客提交申请后后台“研学预约”出现编号，状态为待确认。工作人员查看联系方式、指派负责人、登记沟通、选择场次和填写安排后确认。提交申请不锁名额，确认时事务检查容量；满额或版本冲突必须刷新、沟通后处理，不能绕过服务端检查。确认安排与公开结果显示给本人；内部跟进备注不公开。到访先登记，再完成接待；未到访必须人工登记。

待确认申请可由本人撤回。已确认申请先提出取消或日期/人数变更，原安排保持，工作人员批准或拒绝后才生效。目标场次人数不足时事务回滚，原安排和待处理变更保留。已有申请保存套餐和价格参考快照，后续改名、改价或下架不篡改历史。

咨询保留来源、关联产品/课程和已选规格；工作人员指派、跟进、结束，游客查看本人结果。不构成下单或报名。联系电话是沟通字段，不是记录归属依据；开发身份由服务端随机签发，正式身份适配`wx.login`及服务端代码交换，缺少正式配置会明确失败，不伪造openid。

## 4. 账号和数据权限

管理角色管理内容、业务和账号；内容角色维护内容及媒体但不能读取预约名单；接待角色处理场次、预约、咨询。名单导出还要求单独导出授权，内容角色即使勾选导出也不能导出业务名单。停用账号立即使旧会话失效；角色修改注销其既有会话；不能停用最后一个管理员。上述角色组合是本地技术建议，正式人员及权限由D07确认。

开发管理员登录会话8小时、开发游客会话30天，均属技术测试值。管理员会话用HttpOnly、SameSite=Strict Cookie；写请求另做校验头和来源检查。正式HTTPS、安全Cookie、登录风控、身份恢复及数据留存周期另做部署核定。开发游客令牌到期或主动清理缓存后不能用电话找回旧记录；正式微信身份应以稳定openid恢复本人归属，此能力尚未在公司账号验证。

不填写真实儿童姓名、证件号或照片；不要把真实预约联系人、密码、AppSecret或正式视频加入Git。测试表单明确采用中国大陆手机号校验；对外服务电话支持手机号或电话格式，实际客群与号码规则仍待D07确认。

## 5. 存储、备份和恢复

数据库：`.local/huangqiao.sqlite`；上传文件：`.local/uploads/`；管理员初始凭据：`.local/admin-access.txt`。业务数据和备份目录均不在版本管理中；代码提交不能代替数据库备份。SQLite使用外键、WAL和事务，备份使用一致性数据库快照并复制媒体，清单含SHA-256。

```sh
npm run backup -- backups/manual-001
npm run restore -- backups/manual-001 .local-restored-001
```

备份目录必须不存在；每次选择新的名称。恢复校验数据库、媒体哈希、完整性和外键，只写新的目标目录，禁止覆盖原数据。恢复会清除所有会话，需要重新登录；原账户哈希和业务归属保留，媒体关系也保留。

需要使用恢复副本时，先停止正在运行的开发服务，保留原目录，然后执行 `HQ_DATA_DIR=.local-restored-001 npm run dev`；不要把恢复目标放在已使用的数据库路径。确认样本和媒体无误后再决定正式切换。备份周期、离机保存、加密、保存时长及恢复责任尚待公司确认；本机的一份备份不足以应对电脑丢失或损坏。

`.env.example` 不自动加载。配置以进程环境变量传入；`WX_APPID`、`WX_APPSECRET`仅服务端读取，缺少配置时真实微信登录返回明确错误。本版本拒绝直接以非开发环境启动，CloudBase或其他云部署需要另外完成配置和安全核对。

## 6. 正式环境准备

保留微信原生小程序与独立后台方向；CloudBase仍为优先候选，当前SQLite是本地真实存储验证，不是生产选型批准。云端须验证数据库事务/条件更新、工作人员独立身份、上传与播放、并发、备份和权限；本地SDK、包管理器或测试AppID可用不意味着云服务已开通。

本地开发未购买服务器或云资源。后续费用包括公司账号相关认证与平台要求、云环境套餐、数据库/函数/托管、媒体存储、转码和播放流量、域名及持续运营人工。视频费用随文件大小、更新量和播放量变化，不能承诺固定总价或免费无限上传。将正式账号、业务规则、联系方式和媒体策略确定后，才能安排受控云环境及iOS/Android微信真机测试、体验版、平台审核和发布。

## CR001 修改后的人工复核

刷新后台页面，内容维护先显示乐器与文创两个独立入口。乐器新增或维护时从提琴、吉他、尤克里里、口琴、其他中选择品类；原提琴产品保留在提琴品类下，材质和花纹作为产品说明。小程序在微信工具重新编译后显示首页、乐器、文创、研学、我的；进入乐器按上述五类筛选，没有产品的类别显示空态，不虚构商品。

场次是在某一天、某个时段的接待安排。后台设置日期、时段、人数上限、适用套餐并保存；未暂停且日期未过的场次经公开接口传给预约表单，按游客选择的日期与套餐筛选为可选意向时段。没有匹配时段也可提交意向日期；提交只生成待确认申请，不占用容量。工作人员联系后在研学预约详情中选择场次并确认，服务端检查容量，再将已确认日期、时段、人数和安排显示到游客本人记录。暂停场次不能再选择或新确认，已有记录仍保留；跨场次工坊、导师等资源仍需人工协调。
