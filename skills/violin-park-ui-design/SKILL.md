## 品牌与视觉约束

定位为“东方乐器文化 × 手工制琴 × 现代产业园”的企业品牌及服务小程序。用 Premium、Warm、Craftsmanship、Editorial、Cultural、Violin、Wood 表达精致、温暖、克制、手工质感、文化感与品牌感。

以暖米白为大面积背景、深胡桃木棕为主色、香槟金为少量强调、提琴琥珀棕为辅助。让真实摄影呈现木纹、琴弦、工具、手工与产业场景；用图片、留白和内容层级组织页面。中文衬线用于品牌和章节标题，清晰无衬线用于正文、表单及操作；中英文辅助排版不得降低中文阅读效率。

禁止政务宣传、普通旅游模板、电商商城模板；禁止大量白色描边卡片、所有模块同一种圆角矩形、滥用渐变/阴影/金色，以及用细字、浅色或复杂背景换取“高级感”。不得重绘提供的 YorRay 标志，不把参考图中的手写花字当成新品牌标志。当前品牌栏标题按已确认页面映射，见docs/优化后功能与页面说明.md。参考是方向，验收按设计语言与可用性，不按像素复制程度。

## 业务保护

- 固定五导航：**首页、乐器、文创、研学、我的**；乐器仍包含提琴、吉他、尤克里里、口琴、其他。保留教学、导览、咨询等已有入口。
- 乐器/文创为展示与咨询、线下成交；工业研学真实申请、人工确认；教学包含公开视频；园区参观与服务沿用当前实现。不新增购物车、支付或自动确认。
- 冻结 API、数据库、数据模型、后台逻辑、预约逻辑、登录逻辑、业务路由、功能和字段。不得改变请求、数据取值、条件分支、循环数据、事件处理、权限与状态含义。
- 保留现有完整公司介绍及服务说明，不自行精简；不加入未核实价格、优惠、名额或宣传数据。产品列表封面 **1∶1** 已批准，原图不裁切覆盖，产品详情图库按DEC034为1∶1、下方5px间距；研学套餐卡4∶3、教学视频列表16∶9，其他图库保持现状。
- 若发现严重技术问题，先记录问题、证据、受影响文件与替代方案，提出 Change Request，等待批准；不得先修后报。不能在UI任务中修改共享TS、服务端或后台“顺便修复”。

## 执行流程

1. **基线**：检查 Git 工作区与用户已有文件，记录版本、原件校验和冻结源码摘要。保护原 DOCX、HTML、23张图、用户参考图及归档，不覆盖用户工作。
2. **审查**：优先在微信开发者工具捕获并查看当前原生页面；按首屏、服务入口、园区探索、推荐/页尾记录证据。每项标明截图观察、源码事实或设计判断；写清未执行的真机、辅助功能和异常状态测试。
3. **设计**：按 Design System 说明层级、比例、字体、对比度、点击区域和各状态。列出参考图中与业务冲突的内容及处理，保留全部已有信息和入口。
4. **审批**：给出首页布局方案、文件白名单、验收方法与风险后停止。文档完成不代表设计数值或实施授权已批准。
5. **批准后实施**：Phase 1 只改首页 WXML/WXSS 和仅首页引用的样式文件；使用页面命名空间隔离，全局样式、app.json及TS保持冻结。保留 `bindtap`、`data-page`、`data-id`、数据绑定与路由。新增公共组件、图标导航、定制导航栏或新素材需先确认对应阶段范围。
6. **验证交付**：原生编译、不同宽度和长文本检查、全部入口实际跳转、状态与对比度核查、原件和冻结源码校验。报告通过/失败/未执行/不适用；只有实际测试才称通过。按批准范围记录本地版本，不上传或发布。

## 输出前检查

核对品牌是否克制、中文是否易读、金色是否只作强调、已确认首页五个快捷入口和五导航是否保留、1∶1列表是否保护、正文是否完整、所有状态是否有设计、业务冻结是否满足、原件是否一致、实施是否已获批准。输出实际文件、证据、建议、风险和下一步，阶段完成后按用户要求停止。
